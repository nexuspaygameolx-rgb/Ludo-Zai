# Ludo-Z! (3D Desi Kuti Ludo — Offline P2P + Online Multiplayer + Gemini AI)

A full-stack, zero-trust 3D Desi Ludo platform featuring:
- **Ghar Wali Ulti Kuti (`6 + X` Rule)**: Capture opponent tokens inside their home column after finishing at least 1 token, flipping the capturing token into permanent reverse (`anti-clockwise`) movement with sweep/landing kills that bypass safe zones.
- **Dynamic Twin-to-Single Dice**: Plays with 2 dice in Kuti Mode and automatically locks to 1 die when 3 tokens finish (1 token remaining).
- **Complete Desi & Custom Rule Engine**: Jota (doubling), Tiggi (3-token `delayedRemainingKill`, `fullTiggiCut`, `tiggiShield`), Kati Baghair Ghar Band, Triple-6, 2v2 Jodi mode, and a No-Code Trigger-Condition-Action Custom Rule Builder.
- **Multi-Device Offline P2P ("Apne Apne Mobile Par")**: Zero-internet multiplayer across 2–4 phones via Google Nearby Connections (Wi-Fi Direct + BLE), Local Hotspot LAN, and Bluetooth fallback, complete with live voice chat, text chat, and per-device 3D board rotation.
- **CashMaal Auto Buy/Sell Economy & Adsterra Ads**: Closed-loop Admin Store with automated CashMaal deposit/payout spread, XP Levels (1–100+), Trophies, Gems, Upgradable 3D Dices (Levels 1–5), and server-verified Adsterra rewarded ads.
- **Online-Only Gemini AI Player & Voice Companion**: Real-time voice & text conversation (Male/Female/Friend/GF/Ustaad/Roast personas) where Gemini can also play as an opponent or 2v2 partner when a user's Gemini API key is configured.
- **Modern Admin Web Dashboard**: Live control over Adsterra links, CashMaal rates/credentials, rule presets, 3D store items, and match/wallet audits without needing APK updates.
